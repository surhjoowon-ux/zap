# zap

화면 위 어디에나 띄우는 반투명 실측 자. 메뉴 막대에 자 아이콘으로 상주합니다.
웹사이트나 앱 화면 속 크기를 재고, 실제 물건을 화면에 대고 잴 수도 있습니다.

## 설치

1. [Releases](../../releases/latest)에서 `zap.dmg`를 받습니다.
2. dmg를 열고 `zap`을 `Applications` 폴더로 끌어 넣습니다.
3. 처음 열 때 macOS가 "확인되지 않은 개발자"라며 막을 수 있습니다. Apple 공증을 받지 않은 앱이라서 그렇습니다.
   - **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 누르거나,
   - 터미널에서 다음을 한 번 실행합니다.
     ```
     xattr -dr com.apple.quarantine /Applications/zap.app
     ```

macOS 12 이상, Apple Silicon과 Intel 모두 지원합니다.

## 쓰는 법

- **켜고 끄기**: `⌃⌥R`, 또는 메뉴 막대의 자 아이콘
- **재기**: 자 위를 클릭하면 시작점, 한 번 더 클릭하면 끝점. 다음 클릭은 새로 재기. 자 밖을 누르거나 `esc`로 지우기
- **옮기기**: 자를 드래그. 화살표로 1px(`⇧` 10px)
- **돌리기·늘이기**: 끝의 동그라미를 드래그. 90°마다 착 붙고, `⇧`를 누르면 15°씩. 더블클릭이나 `R`은 90° 회전, `[` `]`는 1°씩
- **화면에서 재기**: `⌃⌥M` 후 드래그하면 사각형의 실제 크기(mm)와 px. `⌘C` 복사
- **눈금**: 위는 실제 길이(cm/inch), 아래는 화면 px. `U`로 단위 전환

## 꾸미기 (메뉴 → Ruler Settings…)

색, 가로 그라데이션, 사진, 진하기, 두께, 눈금 표시를 바꿀 수 있습니다.
사진은 자 두께에 맞춰 한 줄로 들어가고, 길이는 cm 단위로 잘라 반복됩니다.

## 화면 보정

외부 모니터처럼 화면 크기 정보를 주지 않는 화면은 **메뉴 → Calibrate Display…**에서 신용카드(85.60 mm)를 대고 맞추면 화면별로 저장됩니다.

## 직접 빌드

```
./build.sh   # dist/zap.app, dist/zap.dmg
```
